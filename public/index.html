Потрібно вставити конфіг Firebase

Відкрийте index.html, знайдіть firebaseConfig у скрипті і вставте свої значення:

  1. Firebase Console → Build → Realtime Database → Create database.
  2. Build → Authentication → Sign-in method → увімкніть Anonymous.
  3. Project settings → Your apps → Web → скопіюйте конфіг (обов'язково з databaseURL).
  4. Вставте правила з коментаря в кінці файлу у вкладку Rules бази.
