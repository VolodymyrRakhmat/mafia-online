# Mafia Online

Браузерна багатокористувацька гра «Мафія» у реальному часі з розподілом ролей, анімаціями та звуковим супроводом.

## Особливості

* **Мультиплеєр у реальному часі:** синхронізація кімнат, гравців, голосування та ігрових фаз через Firebase Realtime Database.
* **Інтерфейс та анімації:** адаптивний дизайн на Tailwind CSS, 3D-анімації перевертання карток ролей та фонова анімація снігопаду на Canvas.
* **Звуковий супровід:** генерація звукових ефектів ігрових подій через Web Audio API без зовнішніх аудіофайлів.
